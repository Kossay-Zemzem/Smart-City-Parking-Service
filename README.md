# Parking Service (Service Parking)

> [!NOTE]
> This service is part of a microservice orcherstration project. For full details, please visit the **[Smart City Microservices Project](https://github.com/Kossay-Zemzem/Smart-City-Microservices)** main repository.

## Service description

The Parking Service is a core component of the Smart City platform that manages parking facilities and their usage. It provides details on floors and individual spots, including real-time availability in detailed or summary format, and lets users reserve a spot. Each reservation generates an invoice and can be retrieved globally or per customer.

## Tech Stack

* **Framework:** Spring Boot
* **API Style:** GraphQL
* **Database:** H2
